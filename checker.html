🎮 Discord Username Checker

Check 4-character username availability

This will generate combinations like "aaaa", "aaab", etc. You can then check them in the "Check Multiple" section.

ℹ️ About This Tool

What it does:
This tool validates Discord username format and helps you check if 4-character usernames are available.

Username Rules:
• 2-32 characters long
• Letters (a-z), numbers (0-9), and underscore (_) only
• No spaces or special characters

Features:
• Check single usernames
• Batch check multiple usernames
• Generate 4-character combinations
• Works entirely in your browser

⚠️ Important: Discord does not provide a public API for bulk username availability checks. This tool primarily validates format. For accurate availability, use Discord directly.
